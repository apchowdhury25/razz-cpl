# রাজ সিএনপিএল হিসাব — ব্যবহারকারী নির্দেশিকা

[English README](README.md) · বিস্তারিত ধাপে ধাপে হ্যান্ডবুক: **[USER-GUIDE.bn.md](USER-GUIDE.bn.md)** ([English](USER-GUIDE.md))

**রাজ সিএনপিএল**, ঢাকা-এর অভ্যন্তরীণ হিসাবরক্ষণ ব্যবস্থা। দৈনন্দিন প্রাপ্য হিসাব (গ্রাহকের কাছে পাওনা), প্রদেয় হিসাব (ভেন্ডরকে দিতে হবে), প্রকল্প হিসাব, নগদ/ব্যাংক, ভ্যাট/টিডিএস এবং ব্যবস্থাপনা প্রতিবেদনের জন্য ব্যবহার করুন।

এটি ব্রাউজারে চলা একটি সার্ভার-রেন্ডার করা ওয়েব অ্যাপ। অফিসের পিসি বা ছোট ভিপিএস-এ খুলুন। মোবাইল অ্যাপ বা ক্লাউড লগইন নেই।

ডিফল্ট ভাষা ইংরেজি। উপরের বারে **EN · বাংলা** দিয়ে লেবেল বদলান।

## ১. অ্যাপ্লিকেশন খোলা

সিস্টেম চালু থাকলে অফিস পিসিতে:

পেজ না খুললে অ্যাপ্লিকেশন চলছে না। প্রশাসককে চালু করতে বলুন ([প্রথমবার সেটআপ](#১২-প্রথমবার-সেটআপ-আইটি--প্রশাসক))।

## ৩. সংখ্যাগুলোর অর্থ

এগুলো গুলিয়ে ফেলবেন না। ড্যাশবোর্ড পোস্টকৃত লেনদেন থেকে হিসাব হয়; হাতে টাইপ করা মোট নয়।

| শব্দ | অর্থ |
|------|------|
| **প্রাপ্য (AR)** | গ্রাহকের কাছে এখনও পাওনা: পোস্টকৃত ডিমান্ড − বরাদ্দকৃত রিসিপ্ট − ক্রেডিট নোট |
| **রিসিপ্ট** | নগদ বা ব্যাংকে ইতিমধ্যে জমা টাকা |
| **প্রদেয় (AP)** | ভেন্ডরকে এখনও দিতে হবে: পোস্টকৃত বিল − বরাদ্দকৃত পেমেন্ট − ভেন্ডর ক্রেডিট |
| **ভেন্ডর পেমেন্ট** | নগদ/ব্যাংক থেকে ইতিমধ্যে পরিশোধ |
| **টিডিএস প্রদেয়** | ভেন্ডর থেকে কর্তিত উৎস কর, এখনও সরকারে জমা হয়নি |
| **রিটেনশন প্রদেয়** | ঠিকাদার বিল থেকে আটকে রাখা টাকা |
| **ইনপুট ভ্যাট** | যোগ্য ভেন্ডর বিলে রেকর্ডকৃত ভ্যাট |
| **নগদ + ব্যাংক** | প্রারম্ভিক জের + পোস্টকৃত রিসিপ্ট − পোস্টকৃত পেমেন্ট ± স্থানান্তর |

বুকিং বা ডিমান্ড **আয় ও প্রাপ্য বাড়ায়**। মানি রিসিপ্ট **নগদ বাড়ায় ও প্রাপ্য কমায়**। ভেন্ডর বিল **ব্যয়, ইনপুট ভ্যাট ও দায় বাড়ায়**। ভেন্ডর পেমেন্ট **নগদ ও এপি কমায়**।

প্রকল্প লাভ-ক্ষতি = **স্বীকৃত আয় − স্বীকৃত ব্যয়**। এটি “রিসিপ্ট − ভেন্ডর বিল” নয়।

## ৪. ড্যাশবোর্ড

লগইনের পর ড্যাশবোর্ড আসে। এতে থাকে:

- মোট প্রাপ্য, মেয়াদোত্তীর্ণ এআর, বয়স বাকেট
- মোট প্রদেয়, মেয়াদোত্তীর্ণ এপি, বয়স বাকেট
- নগদ, ব্যাংক, নগদ + ব্যাংক
- টিডিএস প্রদেয়, ইনপুট ভ্যাট, আউটপুট ভ্যাট, রিটেনশন
- প্রকল্পভিত্তিক আয়, ব্যয়, ফল, প্রাপ্য, প্রদেয়
- সাম্প্রতিক রিসিপ্ট, বিল, পেমেন্ট, জার্নাল

কোনো অঙ্ক ভুল মনে হলে ড্যাশবোর্ড সম্পাদনা করবেন না। সংশ্লিষ্ট রেজিস্টার খুলুন (ডিমান্ড, রিসিপ্ট, বিল, ট্রায়াল ব্যালেন্স)। এখানে কিছু টাইপ করার নেই।

## ৫. দৈনন্দিন কাজ — প্রাপ্য হিসাব

ডেভেলপার প্রবাহ: **ক্রেতা → ইউনিট → বুকিং → ডিমান্ড → মানি রিসিপ্ট → বরাদ্দ → পোস্ট → ভাউচার প্রিন্ট**।

### ৫.১ ক্রেতা / গ্রাহক

**প্রাপ্য হিসাব → ক্রেতা / গ্রাহক**

- ক্রেতা যোগ করুন (নাম, বাংলা নাম, এনআইডি, ফোন, ঠিকানা)।
- গ্রাহক খুললে তার খতিয়ান দেখা যায়।
- **বিবরণী / Statement** দিয়ে প্রিন্ট বা এক্সেল স্টেটমেন্ট নিন।

### ৫.২ ইউনিট (ডেভেলপার প্রকল্প)

**প্রকল্প → ইউনিট**

- ইউনিট নম্বর, তলা, আয়তন (বর্গফুট), মূল দাম, বিক্রয় দাম লিখুন।
- অবস্থা: Unsold, Reserved, Booked, Sold, Cancelled।
- বুকিং সেভ করলে ইউনিট স্বয়ংক্রিয়ভাবে **Booked** হয়।

### ৫.৩ বুকিং

**প্রাপ্য হিসাব → বুকিং → যোগ করুন**

1. তারিখ, ক্রেতা ও অবিক্রীত ইউনিট বাছুন।
2. সম্মত মূল্য লিখুন।
3. সংরক্ষণ করুন।

সিস্টেম চার কিস্তির **ডিমান্ড** পোস্ট করে (১০% বুকিং মানি, ১৫% ডাউন পেমেন্ট, ৫০% নির্মাণ, ২৫% হস্তান্তর) — মোট সম্মত মূল্যের সমান। এগুলোই প্রাপ্য; রিসিপ্ট নয়।

### ৫.৪ ডিমান্ড / চালান

**প্রাপ্য হিসাব → ডিমান্ড / চালান**

বুকিং থেকে আসেনি এমন অতিরিক্ত ডিমান্ড (বা ঠিকাদারি বিলিং) এখানে।

জীবনচক্র:

`খসড়া → জমা → অনুমোদন → পোস্ট`

শুধু **পোস্টকৃত** ডিমান্ড এআর-এ গণ্য হয়। ভূমিকা অনুসারে Submit, Approve, Post বা Cancel করতে পারবেন।

যে পোস্টকৃত ডিমান্ডে রিসিপ্ট বরাদ্দ আছে, তা বাতিল করা যায় না। আগে রিসিপ্ট রিভার্স করুন (অ্যাডমিন)।

### ৫.৫ মানি রিসিপ্ট

**প্রাপ্য হিসাব → মানি রিসিপ্ট → যোগ করুন**

1. তারিখ, ক্রেতা, পরিমাণ, নগদ/ব্যাংক হিসাব, পদ্ধতি (নগদ, চেক, ব্যাংক ট্রান্সফার, মোবাইল ব্যাংকিং, অন্যান্য)।
2. রেফারেন্স (চেক / টিটি নম্বর)।
3. বকেয়া চালানের বিপরীতে বরাদ্দ করুন। এক রিসিপ্ট একাধিক চালানে ভাগ করা যায়।
4. ডিমান্ডে প্রয়োগের আগে টাকা এলেই কেবল **অগ্রিম / অবণ্টিত অংশ** টিক দিন।
5. খসড়া সেভ করুন, তারপর **পোস্ট**।

সিস্টেম যে নিয়ম ভাঙবে না:

- পরিমাণ শূন্যের বেশি হতে হবে।
- রিসিপ্টের চেয়ে বেশি বরাদ্দ করা যায় না।
- চালানের বকেয়ার চেয়ে বেশি বরাদ্দ করা যায় না।
- অবণ্টিত অংশের জন্য অগ্রিম অপশন লাগবে।

পোস্টের পর **প্রিন্ট ভাউচার** — এ৫ মানি রিসিপ্ট (কথায় পরিমাণ, ইংরেজি ও বাংলা)।

### ৫.৬ এআর বয়স ও খতিয়ান

- **এআর বয়স বিশ্লেষণ** — নির্ধারিত তারিখ অনুসারে বকেয়া, নির্বাচিত **As of** তারিখে। বাকেট: চলতি, ১–৩০, ৩১–৬০, ৬১–৯০, ৯১–১৮০, ১৮১–৩৬৫, ৩৬৫-এর বেশি।
- **গ্রাহক খতিয়ান** — ডেবিট = ডিমান্ড, ক্রেডিট = রিসিপ্ট / ক্রেডিট নোট, চলমান জের।
- **বকেয়া / মেয়াদোত্তীর্ণ** — ডিমান্ড তালিকা থেকে শর্টকাট।
- **অগ্রিম** — পোস্টকৃত রিসিপ্ট যার অংশ এখনও বরাদ্দ হয়নি।

## ৬. দৈনন্দিন কাজ — প্রদেয় হিসাব

প্রবাহ: **ভেন্ডর → বিল (খসড়া) → জমা → অনুমোদন → পোস্ট → পেমেন্ট → বরাদ্দ → পোস্ট → ভাউচার প্রিন্ট**।

### ৬.১ ভেন্ডর

**প্রদেয় হিসাব → ভেন্ডর**

নাম, ধরন (ঠিকাদার, মালামাল সরবরাহকারী, সেবা, পরামর্শক), টিআইএন/বিআইএন, ডিফল্ট টিডিএস % লিখুন। ভেন্ডর খুললে খতিয়ান বা বিবরণী পাবেন।

### ৬.২ ভেন্ডর বিল

**প্রদেয় হিসাব → ভেন্ডর বিল → যোগ করুন**

লিখুন:

- বিল তারিখ ও পরিশোধের তারিখ
- ভেন্ডর ও প্রকল্প
- ভেন্ডরের নিজস্ব বিল নম্বর ও মুশক-৬.৩ রেফারেন্স
- **মোট (গ্রস) পরিমাণ**
- ভ্যাট %, টিডিএস %, রিটেনশন % (বিলের সাথে সংরক্ষিত; পরে মাস্টার হার বদলালে পুরনো বিল বদলায় না)
- ব্যয় হিসাব (নির্মাণ, মালামাল, পেশাগত ফি ইত্যাদি)

ফর্মে লাইভ প্রিভিউ আছে। **সার্ভার সেভের সময় আবার হিসাব করে**:

```
ভ্যাট        = গ্রস × ভ্যাট %
টিডিএস       = গ্রস × টিডিএস %
রিটেনশন     = গ্রস × রিটেনশন %
নীট প্রদেয় = গ্রস + ভ্যাট − টিডিএস − রিটেনশন
```

উদাহরণ: গ্রস ৳ ২৫,০০,০০০.০০, ভ্যাট ১৫%, টিডিএস ৫%, রিটেনশন ৫% → নীট প্রদেয় ৳ ২৬,২৫,০০০.০০।

তারপর **জমা → অনুমোদন → পোস্ট** (ভূমিকা অনুসারে)। পোস্টকৃত বিল সুষম জার্নাল তৈরি করে:

- ডেবিট: প্রকল্প ব্যয় (গ্রস) ও ইনপুট ভ্যাট
- ক্রেডিট: এপি (নীট), টিডিএস প্রদেয়, রিটেনশন প্রদেয়

পোস্টকৃত বিলে আপনি পারেন:

- **টিডিএস জমা** — ব্যাংক থেকে উৎস কর পরিশোধ
- **রিটেনশন নিষ্পত্তি** — আটকে রাখা টাকা ভেন্ডরকে ছাড়া
- **প্রিন্ট** ডেবিট ভাউচার

### ৬.৩ ভেন্ডর পেমেন্ট

**প্রদেয় হিসাব → ভেন্ডর পেমেন্ট → যোগ করুন**

1. তারিখ, ভেন্ডর, পরিমাণ, নগদ/ব্যাংক, পদ্ধতি, চেক/রেফারেন্স।
2. বকেয়া বিলের বিপরীতে বরাদ্দ (পূর্ণ, আংশিক, বা একাধিক বিল)।
3. বকেয়ার চেয়ে বেশি দিলেই **ভেন্ডর অগ্রিম** টিক দিন।
4. সেভ, তারপর **পোস্ট**।

পোস্টে এপি ও নগদ/ব্যাংক কমে। প্রয়োজনে পেমেন্ট ভাউচার প্রিন্ট করুন।

### ৬.৪ এপি বয়স ও খতিয়ান

এআর-এর মতোই: বয়স **পরিশোধের তারিখ** দিয়ে, আপনার বেছে নেওয়া As of তারিখে। ভেন্ডর খতিয়ান: ক্রেডিট = বিল, ডেবিট = পেমেন্ট।

## ৮. নগদ ও ব্যাংক

**নগদ ও ব্যাংক → নগদ ও ব্যাংক** — পেটি ক্যাশ ও ব্যাংক হিসাব, প্রারম্ভিক ও **বর্তমান** জের।

বর্তমান জের = প্রারম্ভিক + পোস্টকৃত রিসিপ্ট − পোস্টকৃত পেমেন্ট ± স্থানান্তর। প্রারম্ভিক অঙ্ককে লাইভ মোট হিসেবে দেখানো হয় না।

- **স্থানান্তর** — নগদ/ব্যাংক হিসাবের মধ্যে টাকা সরানো (যেমন ব্র্যাক ব্যাংক → সিটি ব্যাংক)। পিঅ্যান্ডএল প্রভাব নেই।
- **অন্যান্য আয়/ব্যয়** — অফিস খরচ বা বিবিধ আয়। নগদ/ব্যাংক ও অফসেট খতিয়ান বাছুন।
- **ক্যাশ বুক / ব্যাংক বুক** — তারিখ সীমা, চলমান জের, এক্সেল ও প্রিন্ট।

## ৯. হিসাবরক্ষণ ও কর

### জার্নাল ও খতিয়ান

- **হিসাব তালিকা** — সম্পদ, দায়, মূলধন, আয়, ব্যয় কোড।
- **জার্নাল এন্ট্রি** — প্রতিটি পোস্টকৃত এআর/এপি/নগদ নথি একটি জার্নাল তৈরি করে। ম্যানুয়াল জার্নালও লেখা যায় (ডেবিট = ক্রেডিট হতে হবে)।
- **সাধারণ খতিয়ান** — একটি হিসাব, তারিখ সীমা, চলমান জের।
- **ট্রায়াল ব্যালেন্স** — ডেবিট কলাম = ক্রেডিট কলাম। না মিললে থামুন ও প্রশাসককে বলুন।

পোস্টকৃত জার্নাল চুপিচুপি সম্পাদনা করা যায় না। মূল নথি দিয়ে বাতিল/রিভার্স করুন (অ্যাডমিন)। তাতে রিভার্সিং জার্নাল ও অডিট লাইন হয়।

### কর

**কর → কর সেটিংস** (অ্যাডমিন): ভ্যাট %, টিডিএস ক্যাটাগরি, ডিফল্ট রিটেনশন, কার্যকর তারিখ, সক্রিয়/নিষ্ক্রিয়।

নমুনা কোম্পানির ডিফল্ট (পরিবর্তনযোগ্য, **আইনী পরামর্শ নয়**):

- স্ট্যান্ডার্ড ভ্যাট ১৫%
- নির্মাণ / সিভিল ওয়ার্কস টিডিএস ৫%
- সিমেন্ট / লোহা / স্টিল ২%
- পেশাগত / পরামর্শ (অ-ব্যক্তি) ৭.৫%, (ব্যক্তি) ১৫%
- কারিগরি সেবা (অ-ব্যক্তি) ১০%
- অফিস / গুদাম ভাড়া ১০%
- ডিফল্ট রিটেনশন ৫% (প্রকল্প ও প্রতি বিলেও বদলানো যায়)

**ভ্যাট প্রতিবেদন** ও **টিডিএস প্রতিবেদন** অভ্যন্তরীণ রেজিস্টার (ভেন্ডর, বিল, মুশক, পরিমাণ, জমা)। এনবিআর-এর অফিসিয়াল রিটার্ন নয়।

## ১০. প্রতিবেদন, এক্সেল ও প্রিন্ট

**এক্সেল রপ্তানি** চাপলে আসল `.xlsx` ফাইল হয় (কোম্পানির নাম, ফিল্টার, সময়, মোট)। **প্রিন্ট** বা ভাউচার খুলে ব্রাউজার প্রিন্ট ব্যবহার করুন (এ৫ স্টাইল)।

| প্রতিবেদন | কোথায় |
|-----------|--------|
| এআর / এপি বয়স | প্রাপ্য / প্রদেয় মেনু |
| গ্রাহক / ভেন্ডর খতিয়ান ও বিবরণী | খতিয়ান, বা গ্রাহক/ভেন্ডর পাতা |
| বকেয়া / মেয়াদোত্তীর্ণ | ডিমান্ড ও বিল তালিকা |
| প্রকল্প পিঅ্যান্ডএল, ব্যয়, নগদ প্রবাহ | প্রতিবেদন ও প্রকল্প |
| ক্যাশ বুক, ব্যাংক বুক | নগদ ও ব্যাংক |
| সাধারণ খতিয়ান, ট্রায়াল ব্যালেন্স | হিসাবরক্ষণ |
| টিডিএস প্রদেয়, ভ্যাট / ইনপুট ভ্যাট | কর |
| রিসিপ্ট / পেমেন্ট রেজিস্টার | সেই তালিকায় এক্সপোর্ট |
| দৈনিক / মাসিক লেনদেন | প্রতিবেদন |

মুদ্রা বাংলাদেশি গ্রুপিং ও দুই দশমিক: `৳ ১২,৫০,০০০.০০` ও `৳ ১,০০,০০০.০০` (পশ্চিমা `100,000.00` নয়)। তারিখ **দিন/মাস/বছর** — `DD/MM/YYYY` (যেমন `09/03/2026` = ৯ মার্চ ২০২৬)।

## ১২. প্রথমবার সেটআপ (আইটি / প্রশাসক)

প্রয়োজন: পাইথন ৩.১০ বা নতুন, উইন্ডোজ পিসি বা ছোট লিনাক্স ভিপিএস। এসকিউলাইট সঙ্গে আছে। ক্লাউড অ্যাকাউন্ট লাগে না।

```powershell
cd path\to\accounting-razz
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python run.py --init --seed
```

তারপর [http://127.0.0.1:8000](http://127.0.0.1:8000) খুলুন।

| ফ্ল্যাগ | কাজ |
|---------|-----|
| `--init` | টেবিল না থাকলে তৈরি করে। ডেটা মুছে দেয় **না** |
| `--seed` | নমুনা প্রকল্প, ক্রেতা, বিল, রিসিপ্ট লোড করে। আবার চালালে ডুপ্লিকেট হয় না |
| `--host 0.0.0.0` | ল্যানে শোনে (শুধু বিশ্বস্ত অফিস নেটওয়ার্কে) |
| `--port 8000` | ৮০০০ ব্যস্ত থাকলে পোর্ট বদলান |

লিনাক্স:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --init --seed --host 127.0.0.1 --port 8000
```

`--seed` প্রশিক্ষণ ও প্রদর্শনের জন্য। আসল হিসাবে শুধু `--init` চালান, তারপর নিজের কোম্পানির তথ্য দিন।

সিডের পর নমুনা অঙ্ক যাচাই:

```powershell
.\.venv\Scripts\python -m pytest tests -q
```

দৃশ্যমান ক্রোম ডেমো (প্রতি এন্ট্রি স্ক্রিনে ২০টি মিল রেকর্ড: ক্রেতা ০১ ইউনিট ০১ বুক করে, ভেন্ডর ০১-এর বিল ও পেমেন্ট ইত্যাদি):

| ব্যাকআপ | `backups/` |

**অ্যাপ থেকে (অ্যাডমিন):** প্রশাসন → ব্যাকআপ → **এখন ব্যাকআপ তৈরি করুন**। ফাইল ডাউনলোড করে ইউএসবি বা অফিস ফাইল সার্ভারে রাখুন।

**কমান্ড লাইন থেকে** (আগে অ্যাপ বন্ধ করুন, অথবা বিল্ট-ইন ব্যাকআপ ব্যবহার করুন যা এসকিউলাইট অনলাইন ব্যাকআপ এপিআই ব্যবহার করে):

```powershell
.\.venv\Scripts\python -m app.backup
```

অন্তত একটি কপি অন্য ডিভাইসে রাখুন। অ্যাপ চলাকালীন `data/razz_accounts.db` মুছবেন না।

অ্যাপ চালু হলে ডেটাবেস **নষ্ট করে না**।

## ১৪. উৎপাদন নোট

ছোট অফিস ডিপ্লয়মেন্ট:

1. পাইথন ইনস্টল করুন, ভার্চুয়াল এনভায়রনমেন্ট তৈরি করুন, `--init` চালান (লাইভ ডেটায় সিড নয়)।
2. শক্তিশালী সিক্রেট দিন: এনভায়রনমেন্ট ভেরিয়েবল `RAZZ_SECRET_KEY`।
3. সব ডেমো পাসওয়ার্ড তৎক্ষণাৎ বদলান।
4. লোকালহোস্ট বা অভ্যন্তরীণ আইপি-তে বাঁধুন; এইচটিটিপিএস ও রিভার্স প্রক্সি ছাড়া পাবলিক ইন্টারনেটে খুলবেন না।
5. মাস শেষে সম্পন্ন হিসাব সময়কাল লক করুন।
6. উইন্ডোজ আপডেট বা পিসি সরানোর আগে ব্যাকআপ নিন।
7. একাধিকজন এক মেশিনে কাজ করলে আলাদা উইন্ডোজ ইউজার অ্যাকাউন্ট ব্যবহার করুন।

ঐচ্ছিক এনভায়রনমেন্ট ভেরিয়েবল:

| ভেরিয়েবল | উদ্দেশ্য |
|-----------|----------|
| `RAZZ_DATABASE_URL` | এসকিউলাইট পথ বদল |
| `RAZZ_DATA_DIR` | ডেটা ফোল্ডার |
| `RAZZ_BACKUP_DIR` | ব্যাকআপ ফোল্ডার |
| `RAZZ_SECRET_KEY` | সেশন স্বাক্ষর কী |

## ১৫. নিরাপত্তা

- পাসওয়ার্ড হ্যাশ করা থাকে। সাদা লেখায় সংরক্ষিত হয় না।
- প্রতিটি হিসাব স্ক্রিনে লগইন লাগে। প্রতিবেদনেও লগইন লাগে।
- পোস্টকৃত পরিমাণ ও নথি নম্বর জায়গায় সম্পাদনা করা যায় না।
- ঋণাত্মক পেমেন্ট ও ডুপ্লিকেট নথি নম্বর প্রত্যাখ্যাত হয়।
- অসম জার্নাল প্রত্যাখ্যাত হয়।
- পোস্টকৃত বিলের কর হার পোস্টের দিনের মতোই থাকে।
- লগইন পাতার ডেমো পরিচয় সতর্কবার্তা; উৎপাদন পাসওয়ার্ড নীতি নয়।

ভ্যালিডেশন বার্তা দেখলে (লক করা সময়কাল, অতিরিক্ত বরাদ্দ, ডুপ্লিকেট নম্বর) পড়ে ফর্ম ঠিক করুন। সাধারণ ব্যবহারকারীকে পাইথন ত্রুটির স্ট্যাক দেখানো হয় না।
